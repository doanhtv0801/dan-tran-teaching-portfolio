# Dan Tran — Teaching Portfolio

Single-page portfolio site for Dan Tran's transition from software engineer to secondary teacher of Digital Technologies & Mathematics (targeting New Zealand).

## Contents

- `index.html` — the entire site: markup, CSS, and JS in one self-contained file. Fonts (Newsreader, IBM Plex Sans, IBM Plex Mono) load from Google Fonts; everything else is inline, so the file can be opened directly in a browser or deployed as-is to any static host (Netlify, Vercel, GitHub Pages, S3, etc.) with no build step.

## Sections

Hero (career pipeline) · About · Teaching Areas (Digital Technologies + Mathematics-to-tech mapping) · Teaching Philosophy · From Industry to Classroom · Professional Experience (languages, AWS, tools) · International Experience & languages · Example Student Projects (5) · Teaching Development Journey (7-phase roadmap) · Long-Term Vision.

## Design

"Chalkboard + terminal" visual system:

- **Type** — Newsreader (display/serif), IBM Plex Sans (body), IBM Plex Mono (labels, tags, code-style chips)
- **Color** — warm paper/chalkboard neutrals with a single amber accent
- **Theming** — supports both light and dark viewer preference automatically

## Editing

Open `index.html` in any editor. All styling lives in the `<style>` block at the top; content sections follow in order below the `<article>` tag.
