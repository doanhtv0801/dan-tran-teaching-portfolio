# Dan Tran — Curriculum Vitae / Teaching Portfolio

Single-page portfolio site for Dan Tran's transition from software engineer to secondary teacher of Digital Technologies & Mathematics (targeting New Zealand).

## Contents

- `index.html` — the entire site: markup, CSS, and JS in one self-contained file. Fonts (Crimson Pro, Public Sans) load from Google Fonts; everything else is inline, so the file can be opened directly in a browser or deployed as-is to any static host (Netlify, Vercel, GitHub Pages, S3, etc.) with no build step.

## Sections

Sticky navigation · Hero (CV header + teaching thesis) · About · Teaching Areas (Digital Technologies + Mathematics-to-tech mapping) · Teaching Philosophy · From Industry to Classroom · Professional Experience (languages, AWS, tools, international experience) · Example Student Projects (5) · Teaching Development Journey (7-phase roadmap) · Long-Term Vision.

## Design

Formal "academic CV" visual system, chosen for New Zealand secondary-teaching applications:

- **Type** — Crimson Pro (display/serif, academic feel), Public Sans (body, institutional/legible)
- **Color** — navy + warm gold accent on a light paper background, with a fixed navy sidebar/nav/footer
- **Structure** — numbered sections (01–08) like a formal report, sticky top navigation for quick jumps
- **Theming** — supports both light and dark viewer preference automatically

## Editing

Open `index.html` in any editor. All styling lives in the `<style>` block at the top; content sections follow in order below the `<article>` tag.
